## GitHub Pagesで公開する場合

```bash
cd クライアント/着物マジシャンジャック
git init
git add .
git commit -m "Jack sponsor LP"
gh repo create jack-sponsor --public --push --source=.
# 設定 → Pages → main → / (root) で公開
```

公開URL: `https://{ユーザー名}.github.io/jack-sponsor`
