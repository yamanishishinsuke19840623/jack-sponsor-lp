━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  スポンサーフォーム 自動返信メール設定手順書
  （やまちゃん作業用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

目的：
  フォーム申し込みがあったとき、申し込み者へ自動で
  「ありがとう＋振込先」メールが届くようにする。

作業時間：約10分
必要なもの：やまちゃんの Google アカウント

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 1　Google Apps Script を開く
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ブラウザで以下を開く:
  https://script.google.com

「新しいプロジェクト」をクリック


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 2　コードを貼り付ける
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 左側のファイル欄に「コード.gs」が表示されている
2. その中身を全部削除する
3. 「jack_sponsor_gas.gs」ファイルの中身を全コピーして貼り付ける
4. Ctrl+S で保存（プロジェクト名は「Jack LP 自動返信」などにする）


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 3　ウェブアプリとしてデプロイする
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 右上の「デプロイ」ボタン → 「新しいデプロイ」をクリック
2. 「種類の選択」→「ウェブアプリ」を選択
3. 以下のように設定する:

   ┌─────────────────────────────────┐
   │ 次のユーザーとして実行：自分（自分のGmailアドレス） │
   │ アクセスできるユーザー：全員                      │
   └─────────────────────────────────┘

4. 「デプロイ」ボタンをクリック
5. 権限の確認画面が出たら:
   ・「権限を確認」→ Googleアカウントを選択
   ・「詳細」→「Jack LP 自動返信（安全ではないページ）に移動」
   ・「許可」をクリック

6. デプロイ完了！「ウェブアプリの URL」が表示される
   例：
     https://script.google.com/macros/s/AKfy.../exec

   ★ この URL をコピーしておく ★


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 4　LP の HTML に URL を設定する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

index.html の以下の行を探して URL を貼り付ける:

  var GAS_ENDPOINT = 'YOUR_GAS_ENDPOINT_HERE';
                      ↑ ここをSTEP3でコピーしたURLに差し替え

差し替え後:
  var GAS_ENDPOINT = 'https://script.google.com/macros/s/AKfy.../exec';

その後、git add → commit → push してデプロイ完了。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 5　動作確認
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

kimonomagician.jp でテスト送信して:

  ① 申し込み者のメールに振込先案内が届く
  ② kimonomagician@gmail.com に通知が届く
  ③ やまちゃんの Gmail にも CC で届く

以上で完了！

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  注意点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・メールはやまちゃんの Google アカウントから送信されます
  （送信者欄がやまちゃんのアドレスになる場合がある）
  → 返信先（Reply-To）は kimonomagician@gmail.com に設定済み

・GAS の無料枠：メール送信 100件/日
  スポンサーが毎日100人来ることはまずないので問題なし

・GAS のコードを変更したら「デプロイ管理」から
  「新バージョンとして再デプロイ」すること
